# Security Policy

## Reporting a vulnerability

Please do **not** report security issues in public issues or discussions.

Use **[Report a vulnerability](../../security/advisories/new)** in the Security tab of this repository. Only the maintainer can see it.
Alternatively, email security@vesana.org.

Please include:
- affected component (server, agent, collector, installer)
- Vesana version
- steps to reproduce and potential impact

## What to expect

- Acknowledgement within **3 days**
- An assessment and a planned fix timeline after that
- Credit in the release notes, if you want it

## Scope

In scope: the Vesana server, agent, collector and the install script.

Please do not run tests against **demo.vesana.org** that could disrupt it for others (no load tests, no data destruction). Install your own instance instead – it is free.

## Supported versions

Security fixes are provided for the **latest released version**. Updating via the built-in updater is the supported way to receive them.
